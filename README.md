# Surface Tension

A one-page WebGL portfolio prototype for **Shifat Masud**, design engineer & creative technologist (Dhaka).
Work in progress, deployed on every push to `main`.

- Story and section beats: [docs/story.md](docs/story.md)
- Shifat's requirements, ticked only when verified on the live build: [CLIENT_CHECKLIST.md](CLIENT_CHECKLIST.md)

## Run
```bash
npm ci
npm run dev      # http://localhost:5173
npx vite build   # static output in ./site
```
URL flags: `?grid` (Swiss grid overlay), `?debug`, `?hd`, `?lowq`, `?nogl`.

A full README (architecture, handbook checklist, credits) lands with the final handoff.
